# Overcaption Homebrew tap

[Overcaption](https://overcaption.com) is a free subtitle studio for macOS and Windows that works fully offline.

Install on macOS (Apple Silicon):

```
brew install --cask overcaption/tap/overcaption
```

The app updates itself; `brew upgrade` is not needed. Bugs and feature requests go to the [main repo](https://github.com/overcaption/overcaption/issues).
